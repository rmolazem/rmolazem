# Hi, I'm Ronak Molazem 👋

PhD in mathematics and computer science (INRIA / Université Grenoble Alpes). My doctoral work was in **optical simulation**: spectral analysis of the light transport operator and Monte Carlo algorithms.

In industry, I discovered **medical simulation** and contributed to healthcare simulators, from interventional instruments to ultrasound imaging, built on the [SOFA](https://www.sofa-framework.org/about/features/) framework.

I like exploring systems and tools that have mathematics and physics behind them, and I want to take these skills further into new domains, in optics, healthcare and beyond.

🔎 **Open to new opportunities** in optical and scientific simulation (R&D, France).

### What I work on

- **Optical simulation:** light transport, Monte Carlo methods, spectral and eigenvalue analysis.
- **Medical and physical simulation:** interventional instruments, ultrasound (IVUS) imaging, cardiac motion, calibration against experimental data.
- **Numerical analysis and optimization:** finite element methods, model reduction, parameter optimization.
- **Scientific software:** C++ and Python tools for simulation and plugins.

### Selected Contributions

- **PhD thesis:** *Estimation of eigenvalues of light transport using Monte Carlo algorithms* ([HAL](https://hal.science/tel-03936314v2))
- **[Tearing](https://github.com/InfinyTech3D/Tearing):** SOFA plugin for tearing simulation (refactoring, maintenance, debugging)
- **[InfinyToolkit](https://github.com/InfinyTech3D/InfinyToolkit):** SOFA plugin collecting open-source simulation components and scripts. I added a controller for cardiac motion.

### Tools & Technologies

**Programming:** C++ · Python · MATLAB

**Development Tools:** Git · CMake · Linux

**Simulation Frameworks:** [SOFA Framework](https://www.sofa-framework.org/about/features/) · [High Quality Renderer (HQR)](https://launchpad.net/~csoler-users/+archive/ubuntu/hqr)

### Simulation Plugins & Framework Extensions

- [**BeamAdapter**](https://github.com/sofa-framework/BeamAdapter): Investigated for modelling flexible medical instruments, such as catheters and guidewires, using Timoshenko beam theory.
- [**ModelOrderReduction**](https://github.com/SofaDefrost/ModelOrderReduction): Investigated for its applicability to medical simulation workflows, with the aim of reducing computational costs.
